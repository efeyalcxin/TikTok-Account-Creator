# TikTok Account Creator
#### 🚀  Selenium Based Account Creator for TikTok Web.
1. **Clone the Repo**
2. `pip install -r requirements.txt`
3. `python AccountCreator.py`
#### Functions
* Saves Cookies 
* Saves Email+Password
* Basic Username
* Uses MAIL.TM
